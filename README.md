## `$ whoami`

I'm a software engineer interested in the full stack of engineering problems - from designing APIs and asynchronous services to inspecting binaries and debugging software close to the machine.

- **Backend engineering:** REST APIs, integrations, databases, background jobs, and distributed task processing.
- **Systems programming:** C++, Linux tooling, performance-oriented development, and x86-64 fundamentals.
- **Reverse engineering:** disassembly, decompilation, binary formats, call graphs, cross-references, and debugger-assisted analysis.
- **Automation & AI:** browser automation, workflow orchestration, and local LLM integrations.
- **Infrastructure:** Linux services, containers, deployment, logging, and observability.

I value practical engineering, maintainable architecture, useful automation, and understanding *why* something works - not just making it work once.
